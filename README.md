# 🦉 _ LUMINOUS

A modern and responsive academic resource platform designed for students.

LUMINOUS provides organized semester-wise notes, resources, and academic materials through a clean and intuitive interface, making it easier for students to access study content efficiently.

## 🌐 Live Demo

GitHub Pages:
https://aristotle-creator.github.io/LUMINOUS/

Netlify:
https://luminous-hub.netlify.app/

---

## ✨ Features

- 📚 Semester-wise subject organization
- 🔍 Quick filtering by semester
- 📱 Fully responsive design
- ⚡ Fast loading static website
- 🎨 Modern UI with smooth interactions
- 📂 Organized academic resources
- 🔗 Resource sharing support
- 🏷️ Subject categorization

## 🎯 Purpose

The primary objective of this project :

LUMINOUS is developed as a centralized online platform for storing, organizing, and sharing academic notes and resources, enabling easy access for students while encouraging knowledge sharing across the student community.
- Notes
- Subject resources
- Academic information
- Semester-wise study materials

without navigating through multiple platforms.
